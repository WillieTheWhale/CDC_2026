# Blockers and workarounds

Blockers never stop the backend run. Each one is logged here with the workaround in use.

| Date | Blocker | Workaround | Status |
|---|---|---|---|
| 2026-09-26 | **UNODC IDS has no route fields in the public release.** The IDS download (https://dmp.unodc.org/downloadIDS) needs no login: three public workbooks (2011-2017, 2018-2022, 2023-2026, about 2.3M cases) downloaded fine. But they list only the **country of seizure** (plus date, drug, quantity, location, transport mode). Departure, transit, and destination are restricted-tier fields. | Edges come from (1) a cited corridor table (`backend/trace_backend/seed/corridors.csv`, 234 corridors transcribed from the WDR 2026 annex route maps 7.2.1/7.3.1/7.4.1 and UNODC/EUDA reports) plus plausible neighbour candidates, with (2) yearly volumes estimated by seizure-anchored gravity allocation over real node seizure totals (WDR annex 7.1 for 2015-2024; calibrated IDS backcast for 2011-2014) and cultivation (annex 6.1.1, 6.2.1, 6.2.2). The IDS loader (`ingest/unodc_ids.py::route_hops`) is ready: if a release with route columns is dropped into `backend/data/raw/unodc_ids/`, hops are built per SYSTEM_DESIGN section 6 and replace the allocation for observed years. | workaround live |
| 2026-09-26 | **WDR route maps and country lists (annex 7.2-7.4) are vector PDFs, not tables.** Country shading cannot be parsed reliably. | Transcribed into `corridors.csv` with a citation key per row; `basis` records map vs text. | workaround live |
| 2026-09-26 | **No Jev key** (TypeSafe waitlist). | Live Wire uses `MockJevClassifier` (keyword and rule based) behind the `JevClassifier` interface; the real client (`typesafe-sdk`, pinned `jev-1.13.0`) activates automatically when `TYPESAFE_API_KEY` is set. | mock live |
| 2026-09-26 | **GDELT DOC API rate limit (HTTP 429)** on the first probe. | Poller backs off and retries; on failure the Live Wire replays a bundled sample of real-format articles (`jev/sample_articles.json`) so the WebSocket always streams. Status is reported in `/api/meta` sources. | fallback live |
| 2026-09-26 | **CEPII GeoDist predates 2006 borders** (no South Sudan, Kosovo, Montenegro, Curacao). | Old codes remapped (ROM, ZAR, TMP, PAL, YUG); missing pairs get great-circle distance between World Bank capital coordinates plus a small documented contiguity list. | workaround live |
