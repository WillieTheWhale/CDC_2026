# CDC 2026 Rules and Rubric (copied from the official pages, 2026-09-26)

Sources: https://cdc2026.notion.site/Tracks-and-Datasets-1cb43707696082bda12081ccd3461af2 and https://cdc2026.notion.site/Project-Expectations-and-Judging-331437076960837b91a6016c345ebe97

## Graduate track
- Dataset: World Bank Indicators API (about 16,000 time-series indicators, 45+ databases, many series 50+ years). Difficulty: Hard.
- **Requirement: the project must retrieve data programmatically using the World Bank Indicators API.**
- Suggested areas: global development, economic opportunity, education, poverty, sustainability, health, infrastructure, inequality, country similarity, forecasting, resource prioritization, progress toward development goals.
- Data use: licensing can vary for third-party data; review and follow source and licensing information for selected indicators.
- Prizes: 1st Apple AirPods Pro 2, 2nd Dell Dock Station.

## Ground rules
- **Plagiarism:** no plagiarized code or analyses of the chosen datasets (online sources or other teams). Disqualification.
- **External sources:** allowed to supplement, **must be cited**. Do not consult people outside the group or CDC mentors for significant ideas or techniques.
- **Generative AI:** allowed, but you **must cite** where used. For code snippets from AI tools, write a comment citing it; cite statistical methods too. Our practice: header comment in every AI-written file plus a running log in `docs/AI_USAGE.md`.

## Deliverables
- Devpost submission: fill out the template, submit all code and final visualizations/files.
- At least one visualization component, ideally many (charts, dashboards, interactive websites).
- Final presentation: **7 minutes + 2 minutes Q&A** to a judge panel; open to other teams.

## Rubric (50 points)
| Criterion | Description | Points |
|---|---|---|
| Impact and Applicability | Real-world impact potential; fits the theme and track; addresses the stated problem meaningfully | /10 |
| Completeness | Works as intended; attention to detail; beyond basic prototyping | /10 |
| Innovation and Creativity | Distinctive, novel approach; innovative use of data/tools/models; fresh perspective | /10 |
| Visualization | Clear, meaningful, creative visualizations; easy to read and relevant | /10 |
| Presentation and Communication | Polished, cohesive; clearly explains problem, methods, results; handles questions with clarity | /10 |
